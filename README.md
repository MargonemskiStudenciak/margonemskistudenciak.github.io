# Margonemski Studenciak

Witaj w oficjalnym repozytorium projektu **Margonemski Studenciak**. Znajdziesz tutaj rozwiązania oraz skrypty dedykowane do automatyzacji gry Margonem NI.

## O projekcie
Projekt powstał, aby dostarczyć graczom narzędzia ułatwiające rozgrywkę, w tym automatyzację zadań oraz efektywne expienie. Strona projektu została zaprojektowana z myślą o nowoczesnym designie (styl *glassmorphism*) oraz responsywności.

## Kluczowe funkcje
* **Auto Quester**: Pełna automatyzacja fabuły (1-20 lvl) oraz zadań Zakonu Równowagi.
* **Auto-Hunter**: Wydajny bot do expienia (20-300 lvl) z systemami Anti-Stuck oraz wsparciem Engine API.
* **Nowoczesna strona**: Interaktywny interfejs z animowanym tłem wykorzystującym Canvas API.

## Strona projektu
Zapraszam do odwiedzenia strony: https://margonemskistudenciak.github.io/

## Jak zacząć?
Aby korzystać ze skryptów:
1. Zainstaluj rozszerzenie do przeglądarki typu **Tampermonkey** lub **Violentmonkey**.
2. Wejdź na [stronę projektu](https://margonemskistudenciak.github.io/).
3. Przejdź do zakładki **Projekty** i kliknij przycisk pobierania wybranego skryptu z GitHub Gist.
